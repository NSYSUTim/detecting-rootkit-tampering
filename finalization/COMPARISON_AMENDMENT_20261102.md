# 共同工具比較的輸入與逾時處理修訂

原規約的首次確認嘗試在混合內容的 /var/tmp 完成九十筆工具觀察後，官方 zygarde 於 getdents 隱藏條件逾時。保留這次未完成確認的所有輸出、規約、原程式及 Go 執行堆疊，不將它改稱正常陰性或先導成功，也不計為完成三開機確認。現有資料尚不足以把逾時歸因於 zygarde 或受控模組的哪個機制。

另在只有預定受控檔名的獨立目錄做診斷，透過 zygarde 原有的 PATH 目錄選擇功能加入目標，官方二進位不改，getdents 隱藏條件可正常警報。這支持以獨立目錄控制輸入，但沒有解釋混合目錄逾時的原因。

後續比較使用各確認目錄下的獨立 fixture，僅含原定六個名稱，將其絕對路徑加入 PATH，讓官方 zygarde 與 C 掃描器都列舉該目錄。其他狀態、重複數、方法隨機順序、共同名稱目標、身分差異目標及成本條件維持原規約。

修正量測包裝器，使逾時能保存標準輸出／錯誤並終止自己建立的整個程序群組，再卸載受控模組，避免只終止 GNU time 而遺留其子程序。逾時一律記為未完成，不能算成乾淨結果。若有新的失敗，依原樣保留，不以成功重跑取代。

此修訂在新的三開機確認前固定，確認輸出另用新目錄。原未完成確認、診斷與修訂後確認分開列示。主要結果只支持受控獨立目錄，不宣稱已解決混合真實目錄與所有工具互動。
