# 離線核對的跨平台修正

第一次 Windows 離線重算把保存的 Linux 目標路徑交給 Windows Path，字串因而轉成反斜線，無法與官方輸出的 POSIX 目錄路徑配對。十二狀態先導中七個共同名稱陽性、各兩個 Go 配置，共十四筆因此被離線腳本錯誤標為不符，原生腳本、實收輸出及判定沒有錯誤。該次核對輸出保存在 verification_portability_attempt.json，不作研究結果。

最終核對入口對保存路徑使用 PurePosixPath，不改原始資料、目錄、計時、原生來源或任何樣本。另改為一次解壓至記憶體，避免 gzip 隨機讀取反覆解壓，並對每個正常條件獨立重算一次指紋再逐筆核對。原始 stdout、名稱集合、全部品質門檻、配對順序、計時和及上界檢查均保留。最終 verification.json 才是正式的離線重算結果。
