# 掃描至判讀的歷史量測

本目錄保存本方法在 Linux 6.8／ext4 上的歷史掃描至判讀量測。三次開機各測 128、4,096 與 65,536 項目。每個條件有一次暖機及五次正式量測。本方法保留 45 筆正式觀察和 9 筆暖機，先導另計。

- [本方法的耗時](costs.csv)及[衍生摘要](facts.json)
- [封存](scan_cost_20261102.tar.gz)及[封存收據](RECEIPT.json)
- [公開整理與原始雜湊](../../docs/PUBLIC_CLEANUP_20261117.json)

起點是觀測就緒，終點是完成列舉、還原核對及必要品質檢查。當時的目錄內容、觀察記錄和正式量測值保留。歷史比較階段的行數與原流程見核對紀錄，現有封存只供核對保留的資料。
